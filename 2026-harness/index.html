聽不懂「Harness」、「中間層」？看這裡（30 秒白話版）

AI 模型（像 Claude、GPT、或公司自己架的模型）本身只會「回話」。Harness 就像替模型配上一套「手腳和工具箱」：讓它能讀檔案、跑程式、上網、一步步完成任務，這樣的組合就叫 AI Agent。opencode 是一個開源的 Harness，可以自由換不同模型，所以不會被某一家廠商綁死。

  1. 必做安裝 Claude / ChatGPT 桌面版

    有帳號的人才需要做；兩個都有就兩個都裝。沒有帳號的同仁可以跳過，當天跟旁邊同事一起看。

    1. Claude 桌面版：打開 claude.ai/download，選擇 WindowsmacOS 版下載。
    2. ChatGPT 桌面版：打開 openai.com/chatgpt/download，選擇 WindowsmacOS 版下載。
    3. 雙擊下載好的安裝檔，一路按「下一步 / 安裝」即可。
    4. 打開下載的 .dmg 檔，把 App 圖示拖進「應用程式（Applications）」資料夾。
    5. 打開 App，用你平常的帳號登入，隨便問一句話，確認有回應。

    公司電腦若跳出「需要系統管理員權限」，請找 IT 協助安裝，不要自己想辦法繞過。

  2. 必做安裝 Python

    建議安裝 Python 3.12（3.11 也可以）。版本太新的話，部分 AI 套件可能還沒支援。

    1. 打開 python.org/downloads/windows，找到 Python 3.12.x，下載「Windows installer (64-bit)」。
    2. 雙擊安裝檔。第一個畫面最下方，一定要勾選「Add python.exe to PATH」，再按「Install Now」。
    3. 裝完後，按鍵盤 Win 鍵，輸入 cmd，打開「命令提示字元」（黑色視窗）。
    4. 複製下面這行貼上，按 Enter：
    python --version

    看到類似 Python 3.12.7 就代表成功。

    如果出現「不是內部或外部命令」，或跳出 Microsoft Store：通常是忘了勾「Add to PATH」。重新執行安裝檔 → 選「Modify」→ 勾選 Add Python to environment variables；或改試 py --version。

    1. 打開 python.org/downloads/macos，找到 Python 3.12.x，下載「macOS 64-bit universal2 installer」。
    2. 打開 .pkg 檔，一路按「繼續 / 安裝」。
    3. 按 ⌘ + 空白鍵，輸入「終端機」或 Terminal，打開它。
    4. 複製下面這行貼上，按 Enter：
    python3 --version

    看到類似 Python 3.12.7 就代表成功。Mac 上指令要打 python3，不是 python。

  4. 選做安裝 demo 用的 Python 套件

    老師會 demo 影音下載與語音轉文字、翻譯、自動做 PPT 與旁白配音等工具。想當天跟著跑的人再裝。

    先確認：硬碟至少空出 10 GB，且最好接網路線或穩定 Wi-Fi。裡面有 PyTorch 等大型 AI 套件，第一次安裝可能要 20–40 分鐘，請在有空時進行。

    1. 從上一步的共用資料夾，把 requirements.txt 複製到你電腦上一個新資料夾，例如 C:\harness「文件」裡的 harness 資料夾。
    2. 打開「命令提示字元」（cmd）「終端機」，一行一行複製貼上執行：
    cd C:\harness
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
    cd ~/Documents/harness
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
    這幾行在做什麼？
    • cd：進到剛剛那個資料夾。
    • venv：建立一個「獨立的 Python 小房間」，套件裝在裡面，不會弄亂電腦其他東西。
    • activate：走進這個小房間。成功後，指令列最前面會出現 (.venv)。
    • pip install -r requirements.txt：照清單把所有套件裝好。畫面會跑很多字，屬正常現象。

    當天要再用時，記得先 cd 到資料夾並再執行一次 activate 那行。

    請用「命令提示字元」（cmd），不要用 PowerShell。PowerShell 常會擋掉 activate 這一步。

    清單裡有兩個工具不是 Python 套件，要另外安裝（處理影音和文件轉檔用）：

    winget install ffmpeg
winget install pandoc

    Mac 需先有 Homebrew（brew.sh），若沒裝過可跳過這兩個，當天再處理。

    brew install ffmpeg pandoc

    中途出現紅字錯誤？不用慌，截圖整個視窗帶來現場即可，這正好是老師想實際演練的部分。
